# Politica de seguridad

## Versiones compatibles

Solo se mantiene la version mas reciente publicada de CLA Ebooks Creator. Las correcciones de seguridad se entregan en una nueva version de la aplicacion.

## Reportar una vulnerabilidad

No publiques vulnerabilidades, pruebas de concepto ni informacion sensible en una issue publica.

Abre un reporte privado mediante las funciones de seguridad del repositorio en GitHub. Si esa opcion no esta habilitada, contacta al mantenedor a traves de [el perfil de CLA Tech](https://github.com/AngelCLA) e indica que se trata de un reporte de seguridad.

Incluye, cuando sea posible:

- Una descripcion clara del impacto.
- Pasos para reproducir el problema.
- La version de la aplicacion y de Windows usada.
- Archivos de ejemplo o pruebas de concepto que no expongan informacion personal.
- Una propuesta de correccion, si existe.

Se confirmara la recepcion del reporte y se evaluara antes de publicar detalles. No divulgues el problema hasta que exista una correccion o se acuerde una fecha de divulgacion responsable.

## Alcance

Se consideran relevantes, entre otros, problemas que permitan ejecutar codigo no esperado, acceder o borrar archivos fuera de la seleccion de la persona usuaria, filtrar informacion local o introducir contenido malicioso en ebooks exportados.
